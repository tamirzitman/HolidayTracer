# HolidayTracer

A one-screen web app for a family. Each holiday it asks:

> **<span dir="rtl">איפה אתם בחג?</span>** — <span dir="rtl">אני מארח</span>, or
> <span dir="rtl">מתארח אצל</span> + a family picked from a dropdown.

Sign in with a **phone number and a name** — no password, no email, no code — remembered in a
browser cookie so you only ever type it once. **A Google Sheet is the entire database**, and all
management happens by hand in it. Hebrew (RTL), Jewish holidays on the Israeli schedule.
